# سیستم هوشمند تحلیل تیکت مالی (Financial Ticket Parser Engine)

این پروژه یک سیستم پردازش هوشمند زبان طبیعی (NLP) به زبان پایتون برای تحلیل و استخراج اطلاعات از تیکت‌های پشتیبانی مالی است.

## ویژگی‌ها:
- **استخراج مبلغ (به تومان)**: پشتیبانی کامل از واحدهای تومان، ریال، هزار، میلیون و ترکیب‌های متنی یا عددی.
- **استخراج ساعت**: تبدیل فرمت‌های مختلف به ۲۴ ساعته (با لحاظ کلمات عصر، شب، بعدازظهر).
- **استخراج تاریخ**: پشتیبانی از تاریخ‌های شمسی کامل، نسبی (امروز، الان) و ارجاع به تاریخ ثبت تیکت.
- **استخراج شماره کارت مبدا و مقصد**: تشخیص کارت ۱۶ رقمی براساس ساختار و کلمات کلیدی (از کارت، کارت من، به کارت و غیره).
- **تشخیص درگاه و نام صاحب کارت مقصد**: تفکیک درگاه‌های شاپرک، کاسپین، کارت‌به‌کارت و استخراج اسامی مقصد.
- **سرویس REST API پرسرعت (FastAPI)** و **رابط خط فرمان (CLI)**.
- **کارایی و سرعت فوق‌العاده**: پردازش ۵,۳۵۳ تیکت در کمتر از ۳ ثانیه (میانگین ۰.۵۳ میلی‌ثانیه برای هر تیکت).

## راهنمای استفاده:

### ۱. اجرای سرویس وب (REST API)
```bash
uvicorn src.main:app --reload --port 8000
```
ارسال درخواست POST به مسیر `/api/v1/extract`:
```json
{
  "ticketPostedTime": "20.08.26 - 01:53",
  "messages": [
    {
      "sender": "customer",
      "text": "سلام مبلغ ۱ میلیون تومان در تاریخ ۱۴۰۵/۰۵/۲۹ ساعت ۱۲:۳۰ واریز کردم."
    }
  ]
}
```

### ۲. اجرای CLI
```bash
python3 src/cli.py --text "مبلغ ۵۰۰ هزار تومان ساعت ۱۶:۲۰ واریز شد"
```

### ۳. اجرای تست‌ها و بنچمارک
```bash
PYTHONPATH=. pytest tests/
PYTHONPATH=. python3 tests/benchmark.py
```
